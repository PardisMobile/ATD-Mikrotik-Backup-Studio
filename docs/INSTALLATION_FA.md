# راهنمای نصب فارسی

> این راهنما عمومی است. پیش از اجرای اسکریپت نصب سرور، آن را با ساختار واقعی وب‌سرور و مسیر بکاپ خود بررسی کنید. روی سرور عملیاتی بدون نسخه پشتیبان و بررسی قبلی اجرا نکنید.

## ویندوز

1. پوشه پروژه را استخراج کنید.
2. فایل `windows-client/Generate-MikroTik-Backup.bat` را اجرا کنید.
3. اطلاعات اتصال روتر و SFTP را وارد کنید.
4. ابتدا حالت SFTP را به تنهایی آزمایش کنید و وجود فایل کامل `.backup` در مقصد را بررسی کنید.
5. برای ساخت EXE، فایل `windows-client/Build-EXE.bat` را اجرا کنید؛ خطاهای کامپایل را نادیده نگیرید و خروجی موفق را بررسی کنید.

## فعال‌سازی تلگرام

1. از طریق BotFather یک ربات بسازید و توکن را محرمانه نگه دارید.
2. شناسه عددی مقصد (گفت‌وگوی خصوصی، گروه یا کانال) را مشخص کنید و دسترسی لازم را به ربات بدهید.
3. یک HTTPS endpoint برای relay تنظیم کنید.
4. مطمئن شوید PHP می‌تواند فقط به پوشه بکاپ موردنیاز دسترسی داشته باشد. برای پوشه‌ای زیر `/root`، به وب‌سرور دسترسی عمومی ندهید و مجوزهای والد را به‌صورت گسترده تغییر ندهید.
5. یک فایل آزمایشی غیرحساس ارسال کنید و مطمئن شوید اندازه فایل پس از دریافت با فایل اصلی برابر است.
6. وضعیت ارسال و جلوگیری از ارسال تکراری را بررسی کنید.

## نکات امنیتی مهم

- توکن بات، توکن relay و رمز پنل را در Git یا لاگ‌های عمومی قرار ندهید.
- از رمز قوی و HTTPS استفاده کنید.
- PHP را با کاربر وب‌سرور اجرا کنید؛ آن را root نکنید.
- از `chmod 777` استفاده نکنید.
- پوشه بکاپ را به‌صورت مستقیم و عمومی در DocumentRoot قرار ندهید.
- حذف فایل واقعی باید فقط پس از ورود مجاز، اعتبارسنجی مسیر، محافظت CSRF و تأیید کاربر انجام شود.
- پیش از هر به‌روزرسانی، از تنظیمات و بکاپ‌ها نسخه پشتیبان بگیرید.
