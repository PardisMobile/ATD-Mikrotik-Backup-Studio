# راهنمای نصب ATD MikroTik Backup Studio

## خروجی ویندوز

1. برنامه EXE/ژنراتور را اجرا و مقادیر اولیه را وارد کنید.
2. در حالت Telegram/Panel، فایل `generated-output/install.sh` ساخته می‌شود. این فایل شامل تنظیمات محرمانه همان نصب است؛ آن را در گیت‌هاب یا فضای عمومی قرار ندهید.
3. فایل `paste-into-routeros-terminal.txt` برای نصب اسکریپت و زمان‌بندی روی MikroTik ساخته می‌شود.

در حالت SFTP-only نیازی به پنل و `install.sh` نیست؛ خروجی RouterOS و در صورت نیاز `create-sftp-directory.txt` را استفاده کنید.

## نصب سرور (حالت Telegram/Panel)

1. فقط فایل `install.sh` را به سرور لینوکس منتقل کنید.
2. اجرا کنید:

   ```bash
   sudo bash install.sh
   ```

3. اسکریپت فایل‌های پنل را از GitHub دریافت و SHA-256 آن‌ها را بررسی می‌کند. در صورت عدم تطابق نسخه‌ها نصب متوقف می‌شود.
4. تنظیمات خصوصی در `/etc/atd-mikrotik-backup-studio/config.php` ایجاد می‌شوند. نصب مجدد، تنظیمات موجود و پورت‌های تخصیص‌یافته را حفظ می‌کند.
5. آدرس HTTPS و پورت در پایان نمایش داده می‌شوند. گواهی پیش‌فرض self-signed است و ممکن است مرورگر هشدار نشان دهد.
6. اگر دسترسی بیرونی مسدود است، پورت TCP نمایش‌داده‌شده را در فایروال سرور یا پنل ارائه‌دهنده، پس از بررسی سیاست موجود، مجاز کنید. نصب‌کننده خودش قوانین کلی فایروال را تغییر نمی‌دهد.

## به‌روزرسانی

روی سرور اجرا کنید:

```bash
sudo atd-mikrotik-backup-update
```

به‌روزرسانی کد پنل را در مسیر موقت دریافت و بررسی می‌کند، از کد قبلی نسخه پشتیبان می‌گیرد و فقط فایل‌های برنامه را جایگزین می‌کند. تنظیمات اولیه، رمزهای ذخیره‌شده، سابقه ارسال و فایل‌های بکاپ حفظ می‌شوند. این فرمان فقط سرویس PHP مربوط به ATD را restart می‌کند.

## وضعیت آزمون

موفقیت CI به معنی آزمون کامل روی سرور واقعی نیست. قبل از استفاده عملیاتی، نصب و به‌روزرسانی را روی یک سرور آزمایشی بررسی کنید و ارسال واقعی SFTP و تلگرام را آزمایش کنید.
